# Operator

An autonomous AI employee that turns a short company request into **completed** work,
proves it with independent verification, and only interrupts a human when policy or
ambiguity requires it.

> **Pitch:** An employee that finishes the job, proves it, and only interrupts you when it truly matters.

## The 90-second story

1. Type: `Process this month's pending vendor invoices.`
2. Operator understands the goal, loads AcmeCorp policy, extracts inbox PDFs, and works the procurement portal in a real browser.
3. INV-1003 (over $5k) pauses for one approval card (summary + policy + risk). Approve → resume.
4. Injected faults (session expiry / renamed Submit button) recover; INV-1010 injection is recorded, not obeyed.
5. Proof screen: per-invoice outcomes + independent **Verified** panel. Details shows tokens/cost/timeline — not the main path.

Reproduce headlessly: `make portal` then `make demo` (INV-1001 / 1008 / 1010). Full script: [docs/DEMO.md](docs/DEMO.md).

## Dual path (honest)

| Path | When | Browser writes |
|------|------|----------------|
| **Haiku a11y loop** | `ANTHROPIC_API_KEY` set (CLI/UI), or `use_browser_loop=True` | Observe compact a11y tree → LLM picks **one** action → tool → repeat until postcondition |
| **FakeLLM CI shortcut** | `make test` / `make eval` (default) | High-level `submit_invoice` (still **real Playwright** fills/clicks) for speed/cost |

Policy decisions and verification are **never** FakeLLM. DesktopTool remains **STUB**.

## Quickstart

```bash
cp .env.example .env
# Optional: paste ANTHROPIC_API_KEY for real Haiku understand/plan + a11y loop
make setup
make portal    # http://127.0.0.1:8765
make ui        # http://127.0.0.1:8877
make lint && make test && make eval
make demo      # requires portal; subset INV-1001,INV-1008,INV-1010
```

Never commit `.env`.

## Limitations / next steps

- Full 12-invoice **real-LLM browser** eval every CI run is out of scope (cost); FakeLLM evals + P4 Haiku decision AC + one Haiku a11y loop test cover the bar.
- Invoice **decisions** are deterministic `PolicyEngine` (LLM owns understand/plan/browser_step structure).
- DesktopTool STUB — no general computer-use.
- CLARIFY FSM exists but the demo path states assumptions instead of blocking on open questions.
- Multi-tenant SaaS / embeddings-required memory — explicit non-goals.
