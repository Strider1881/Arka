# Operator

An autonomous AI employee that turns a short company request into **completed** work,
proves it with independent verification, and only interrupts a human when policy or
ambiguity requires it.

> **Pitch:** An employee that finishes the job, proves it, and only interrupts you when it truly matters.

## Status

**Phases P0–P10 implemented** for the AcmeCorp invoice scenario (FakeLLM/CI path).
Real Anthropic path is wired (`AnthropicClient`) but gated on `ANTHROPIC_API_KEY`
(not present in the build environment — not faked as a real-LLM pass).

Demo GIF: see local run via `make demo` / UI; embed link TBD after recording.

## The 90-second story

1. Type: `Process this month's pending vendor invoices.`
2. Operator understands, plans, and works through AcmeCorp Procure (browser + PDFs + policy).
3. One approval when policy requires it; then a one-screen proof report with verifier checks.

See [docs/DEMO.md](docs/DEMO.md).

## Quickstart

```bash
# Python 3.12+ and uv
cp .env.example .env
make setup
make portal    # http://127.0.0.1:8765  (operator@acmecorp.test / PORTAL_OPERATOR_PASSWORD)
make ui        # http://127.0.0.1:8877  Operator HTMX UI
# or
make run       # CLI headless with --auto-approve
make lint && make test
make eval      # writes evals/results/summary.md
make demo      # CLI subset against running portal
```

| `make lint` / `make test` | Works |

## Architecture

Package: **`ark_operator/`** (SPEC `operator/` renamed — stdlib clash). Event-sourced runtime,
independent verifier, HTMX+SSE UI. Diagrams: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Design decisions

See [docs/DECISIONS.md](docs/DECISIONS.md): HTMX+SSE, sqlite3, custom backoff,
`PORTAL_OPERATOR_PASSWORD`, 12 POs, session_expiry N=5, untrusted-data delimiters.

## Limitations / next steps

- Real-LLM planning quality not measured here (no API key in CI). FakeLLM + deterministic policy covers AC.
- Full 12-invoice browser eval is slower; CI uses filtered scenarios + decision unit coverage.
- DesktopTool remains STUB.
- Embeddings / multi-tenant connectors out of scope.
